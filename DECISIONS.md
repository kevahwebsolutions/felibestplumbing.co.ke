# Decisions

Decisions taken while executing `REVAMP_PROMPT.md` without questions. Newest context first within each area.

## Repository and migration
- Branch `revamp/clay-2026`. `node_modules` removed from the index and `.gitignore` added; history was not rewritten.
- All legacy files moved with `git mv` into `legacy/`; nothing deleted. `docs/legacy-inventory.md` and `config/legacy-redirects.json` are generated by `scripts/build-legacy-inventory.mjs` from `scripts/legacy-map.mjs`.
- `heater-installations.html` actually contains **Gutter Installations** content (and the same page title is "Water Heater Installation"), so it redirects to `/services/gutter-installations`. Water heating is covered by the solar water heater and electric instant shower pages.
- `services-item01/02/03` redirect to the matching service (residential, commercial, bathroom renovations). `gallery2/3` merge into `/gallery`. `header.html`, `product.html`, `shop-item.html` and `single-post.html` redirect to the nearest real route.
- Redirects are issued as 301 (`statusCode: 301`), including capitalised names, the file with spaces and non-breaking spaces, `.html` and extensionless variants.
- `interior-design.html` maps to `/services/interior-design` (the page is general interior design, not only bathrooms).

## Stack
- Tailwind CSS v4 is configured in CSS (`@theme` in `globals.css`), which replaces `tailwind.config`. Tokens live in one place.
- shadcn/ui is hand-assembled on Radix primitives (dialog, accordion, tabs, slider, switch, checkbox) instead of running the shadcn CLI, so the components carry the clay styling from the start.
- TanStack Table is pinned to v8.21 (stable API). TypeScript is pinned to 5.9 and ESLint to 9 to match `eslint-config-next`.
- Auth uses iron-session plus bcryptjs (smaller than Auth.js for a single admin). Login is rate limited per IP and per email.
- Rate limiting is in memory, so the app must run as a single process (documented in README, PM2 config uses one instance).
- Lenis smooth scroll is disabled under `prefers-reduced-motion` and on touch devices (native momentum scroll feels better there).
- The old third-party WhatsApp widget is replaced by native clay buttons using `wa.me/254798174201` with a prefilled message.
- Brand icons are small inline SVGs because lucide-react v1 no longer ships brand icons.

## Design
- Orange `#ff4917` fails WCAG AA with white text, so the CTA colour is `#d63a0c` to `#bf3208` (4.7:1 on white). `#ff4917` is kept as a decorative accent token. Body text uses `#34424f`, muted text `#566370`, both AA on the pastel surfaces. Sky blue is used for fills, never for small text.
- The logo has black lettering that disappears on navy, so the site uses the white-wordmark version (`logo.webp`, trimmed to `logo-white.webp`) on a navy clay disc. PWA icons are that logo on brand navy.
- 3D clay icons are gradient spheres with inner highlight and shade carrying a Lucide glyph, plus hand-drawn SVG drop and wrench art. No external image dependencies.

## Content
- The founder is shown as "Mr. Felix, CEO and Founder" (as on the old home page). The old About page named "Felix Odongo", which is used only in structured data.
- Claims reused from the old site: 4+ years combined experience, 1300+ installs, 600+ repairs, on-time guarantee, 100% satisfaction, you approve the price first, fully licensed technicians, 24/7, family-owned. "Established 2020" comes from the logo and is used in structured data only. No certifications, awards or addresses were invented.
- Old US content removed: Virginia address, USD prices, "nationwide", HomeAdvisor statistics, expired 2021 coupons, US coverage list, US HVAC blog posts.
- Pricing page: the rate guide is an indicative KES range for common jobs and is labelled as a guide. Plans say "Ask for a quote" rather than inventing monthly fees. Default offers restate the old site's true "no extra charge for same-day, evening or weekend" promise and the old "drain testing" special without a made-up discount. Offers are editable in Admin, Settings.
- Coverage areas list well-known Nairobi areas as a starting point, flagged to the owner to confirm.
- Testimonials: reused verbatim as instructed (four distinct texts). They look like template content; flagged in README.
- Blog: 8 new original articles written for Nairobi homes and businesses. Prices and legal claims were avoided.
- The old shop page only contained 12 distinct products (one duplicate faucet listing merged). To reach 24 seeded products, 12 generic starter lines were added as **unpublished drafts** so nothing unreal is shown to customers.
- Product prices: old USD at 130, rounded to nearest 50, all marked `isPlaceholderPrice`, with a dashboard banner and bulk "Confirm prices" action.

## Shop and orders
- Prices are never trusted from the browser: the order endpoint re-reads price and stock from the database inside a transaction and decrements stock. Cancelling an order returns stock.
- Order reference is `FP-` plus six characters from an unambiguous alphabet. The confirmation page is public by reference, as the brief requires.
- Honeypot field plus per-IP rate limits on forms (6 per 10 min) and orders (8 per 10 min).

## Analytics
- Visitor id is a daily-rotating salted SHA-256 of IP and user agent, truncated to 20 hex characters; raw IPs are never stored. Sessions come from a `sessionStorage` id created in the browser.
- Days, hours and weekdays use East Africa Time (UTC+3). Bounce rate = sessions with a single event.
- Time series for completed days come from `daily_stats` (nightly roll-up, `npm run rollup`); today is computed live. Breakdowns are computed from indexed events.
- `/admin`, `/api`, `/media` and bots are ignored. Country comes from `CF-IPCountry` when present.
- Demo seed refuses to run when `NODE_ENV=production`, uses a deterministic random generator and tags demo rows so `--clear` removes them.

## Security
- CSP, X-Frame-Options, Referrer-Policy, Permissions-Policy, HSTS and nosniff headers in `next.config.mjs`. `script-src` needs `'unsafe-inline'` for Next.js inline bootstrap scripts and JSON-LD.
- Uploads: MIME and extension allow-list, 6 MB cap, pixel limit, sharp re-encode to webp (strips metadata), random file names, strict name regex on read.
- CSV exports neutralise spreadsheet formula injection.
- The Web3Forms key moved to `WEB3FORMS_ACCESS_KEY`. It stays in git history and must be rotated (flagged in README).

## Not done on purpose
- M-Pesa Daraja is not implemented; only the `PaymentProvider` interface exists.
- No Lighthouse numbers are claimed: see `docs/QUALITY.md` for what was and was not measured.
